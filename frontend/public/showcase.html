Capabilities

Every hard problem, solved

Built to handle exactly the real-world failures that break basic resume parsers.

🏢
Company normalization
Resolves 100s of company aliases and abbreviations. "Goog", "IBM Corp", "Big Blue", "MSFT Azure" all resolve to canonical names. Acquisition chains tracked.
entity resolution alias mapping NAICS codes
🗺️
Skills taxonomy graph
Normalizes skill abbreviations (JS → JavaScript, K8s → Kubernetes), clusters into 7 domains, and infers proficiency level from surrounding context.
ontology 7 clusters proficiency inference
🎓
Education scoring
Normalizes school names and assigns Elite / Target / Standard tiers. Covers Ivy League, MIT, Stanford, Caltech, CMU, top global institutions.
school normalization elite tier degree parsing
📋
Messy resume handling
Works on inconsistent formatting, multi-column layouts, missing dates, implicit company names, merged sections, and OCR-style noise.
robustness multi-column error recovery
📎
Multi-format ingestion
Accepts PDF (text-based), DOCX, plain TXT, and pasted text via REST API. File upload and text endpoints, CORS enabled, multipart/JSON.
PDF DOCX REST API
📊
Confidence scoring
Per-field confidence scores (0.0–1.0), parsing issue flags, normalization audit trail, overall extraction confidence. Full transparency on uncertain data.
precision audit trail confidence 0–1
